# Product

<!-- impeccable:product-schema 1 -->

## Platform

desktop

## Users

Curious explorers, math enthusiasts, students, and casual users who want to find where significant dates (birthdays, anniversaries, historical milestones) appear in the infinite transcendental digits of Pi ($\pi$).

## Product Purpose

A focused, immersive, beautifully engineered native desktop application that searches, visualizes, and streams the digits of $\pi$ in real time to locate dates of birth and generate verified certificates of their mathematical existence.

## Positioning

Unlike web-based static search boxes with bare text outputs, Pi Birthday Quest turns searching for dates in $\pi$ into an interactive scientific instrument: live mathematical streaming, precise surrounding tape inspection, probability calculations, and exportable certificates—built in pure, fast native Rust with 60 FPS graphics.

## Operating Context

Runs natively on Linux, Windows, and macOS desktop environments without browser overhead, offering instant offline verification for local ranges and asynchronous deep-index lookups across 200 million digits.

## Capabilities and Constraints

- Date parsing across international formats (`DD/MM/YYYY`, `MM/DD/YYYY`, `YYYY/MM/DD`, `DD/MM/YY`, `DD/MM`, and arbitrary numeric strings).
- Strictly avoid hardcoding or using private user dates as presets or defaults.
- Real-time digit streaming engine with variable speed and auto-seeking.
- Multi-threaded non-blocking architecture preventing any UI frame drops.
- High-contrast, mathematically elegant visual hierarchy following the craft floor rules.

## Product Principles

1. **Restraint over Gimmickry**: Precision typography and purposeful layout over cluttered emojis or noisy card stacks.
2. **Scientific Instrument Feel**: Crisp data readout, live digit odometer, and exact contextual proof.
3. **Privacy First**: Dates searched locally or queried securely; no private user dates used as default examples.
4. **Fluid Responsiveness**: Never block the rendering thread; async computation keeps animations at native refresh rate.
